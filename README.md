
# C Calculator

A simple calculator program written in C.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used

- C
- Standard C Library

## How to Run

1. Download or clone this repository.
2. Compile the C program using a C compiler.
3. Run the program.
4. Enter two numbers and choose an operator.
